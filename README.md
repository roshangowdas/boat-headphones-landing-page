# 🎧 Boat Rokerz Landing Page

A modern **product landing page UI** built using **HTML and CSS** that showcases the **Boat Rokerz headphone series** with a clean layout, gradient hero section, and responsive design.

This project focuses on creating a **visually appealing landing page** similar to real-world product websites used by brands to promote their products.

---

## 🚀 Features

* Modern **Hero Section Design**
* Clean **Navigation Bar**
* Product **Showcase Layout**
* **Hover Animations** for product image
* **Social Media Sidebar**
* **Responsive Layout**
* Stylish **Gradient Background**
* Google Fonts & Font Awesome Icons

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts
* Font Awesome Icons
